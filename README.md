# Учебный планер

Устанавливаемое PWA для учебных заданий, сроков и прогресса. Лабораторная работа 6.

- Приложение: https://ddkane.github.io/study-planner-lab6/app/
- Лендинг: https://ddkane.github.io/study-planner-lab6/
- Сборка: https://github.com/ddKane/study-planner-lab6/releases/tag/v1.0.1
- Опрос: https://docs.google.com/forms/d/e/1FAIpQLSdFgoZtwk1cscr_a_ED8lYKxXO9--pZwq2vXUy78XRCmL_cvQ/viewform

Публикация проверена 5 октября 2026 года. Установка на физических телефонах, отзывы 2–3 тестировщиков и минимум 10 настоящих ответов ещё ожидаются. Иконка A применяется предварительно.

## Возможности

- Добавление, редактирование, выполнение и удаление заданий.
- Предметы, сроки, приоритеты и примечания.
- Поиск, фильтры и сортировка.
- Статистика выполнения по предметам.
- Офлайн-работа после первого открытия; экспорт и импорт JSON.

Все задания хранятся в localStorage этого браузера. Регистрация не нужна. Между устройствами нет автоматической синхронизации: перенос выполняется резервной копией. Начальная база пуста; демонстрационные задания добавляются только по кнопке.

## Запуск

Требуется Node.js 20 или новее. Зависимости для приложения устанавливать не нужно.

```text
node scripts/build.mjs
node scripts/serve.mjs
```

Открыть http://127.0.0.1:4173/app/. Прямое открытие index.html через file:// не обеспечивает установку и service worker.

## Проверки

```text
node --test tests/domain.test.mjs
```

Проверяются корректность календарных дат, поля задания, импорт, фильтры, сроки и расчёт статистики. Журнал браузерных проверок находится в verification.json.

## Публикация

`dist` — готовая статическая сборка. Для GitHub Pages используется копия сборки в `docs`: Settings → Pages → Deploy from a branch → main → /docs. Для Netlify можно загрузить dist или использовать настройки netlify.toml. Публичное размещение должно использовать HTTPS.

Android: открыть приложение в Chrome → меню ⋮ → «Установить приложение» либо «Добавить на главный экран» → подтвердить. Для проверки офлайн сначала открыть приложение и дождаться подготовки кеша.

## Опрос иконок

В `metadata` находятся две иконки 512×512, сравнительное изображение и баннер 1024×500. Используется сравнительный опрос Google Forms с минимум 10 реальными участниками. Фактические ответы не подменяются демонстрационными данными.

```text
python scripts/analyze_survey.py responses.csv --out survey-results.json
```

Основной показатель — выбор иконки для установки; остальные вопросы описывают восприятие. Это опрос предпочтений, не эксперимент с измерением конверсии. До сбора данных применяется исходный вариант A; итоговый выбор требует реальных ответов.

## Обновления

При изменении файлов приложения нужно изменить строку CACHE в public/app/sw.js. Новая версия устанавливается по кнопке «Обновить приложение» после сохранения открытого задания. Задания в localStorage сохраняются при обновлении.

Версия 1.0.1. Сборка не является APK или AAB.
